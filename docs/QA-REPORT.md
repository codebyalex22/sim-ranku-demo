# QA-звіт: демо-сайт «Сім ранку»

Односторінковий демонстраційний сайт вигаданої пекарні-кав'ярні для портфоліо.
Стек: HTML, CSS, JavaScript без фреймворків, залежностей і збирання.
Стан на 15.11.2026. Два незалежні аудити Codex: 7/10, потім 8/10 (усі зауваження P1 і P2 закрито).

## Не перевірено

- iPhone / iOS Safari і Android Chrome на реальних пристроях, сенсорні жести.
- Firefox і Windows (там замість PT Serif буде Georgia).
- Зчитувачі екрана (VoiceOver, NVDA).
- Режим зменшення анімації: лише за кодом, без емуляції.
- Реальне надсилання форми: обробника немає, працює лише демо-режим.
- Lighthouse / PageSpeed після публікації на реальному домені.
- Соцпрев'ю в Telegram, Facebook, LinkedIn: `og:image` вказано повною адресою на GitHub Pages, але вигляд картки в самих соцмережах не перевірено.
